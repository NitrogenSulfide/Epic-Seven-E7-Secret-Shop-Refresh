# v0.1.1 — Administrator restart

Mouse is now the default for new settings; existing saved modes are preserved.

If Mouse mode needs administrator permission to control your selected game,
Start Refresh offers to save settings and reopen the app through Windows UAC.
Accept the prompt, then select the game and press Start again. Cancelling keeps
the app open without sending Mouse input. ADB and non-elevated games need no restart.

Download **E7ShopRefresh-0.1.1.zip** and extract the whole ZIP. Python is included.
Back up your existing `runtime` settings/history before updating. Tested clients:
Google Play Games on PC Developer Emulator and native STOVE; other methods remain untested.
