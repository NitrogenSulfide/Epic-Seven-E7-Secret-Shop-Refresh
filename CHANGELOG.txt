0.1.0 · First release preview (rc49)

rc49
• Mouse confirmations recheck the intended action, item/cost and observed
  button on a fresh capture. Background animation and tiny OCR-bound shifts
  no longer incorrectly stop an otherwise unchanged confirmation.
• Changed-confirmation diagnostics retain both dialog crops for comparison.
  Added consecutive-refresh and fresh item/cost/Stop regression checks.

rc48
• Mouse confirmation retries incomplete OCR within its existing five-second
  wait. Item, cost and fresh-dialog checks still precede the confirmation click.
• Text mismatches and changing confirmations now save private dialog crops,
  as missing buttons already did, to support diagnosis without guessing.

rc47
• Hidden-home reveal tolerates animated, dark or sparse wallpapers and
  incidental OCR lettering. When no controls are recognized, try one center
  click, wait briefly, then recognize the shop icon and verify shop entry.
• Freshly visible controls are used without an extra reveal click. Known
  dialog/loading labels and blank captures still block the reveal attempt.

rc46
• Fixed native Mouse purchases stopping at the STOVE Buy dialog: its combined
  gold-price/action button exceeded the old width limit. Purchase confirmations
  now allow that size; item, price and fresh-dialog checks still apply.

rc45
• Native Mouse home entry recognizes Sanctuary, Secret Shop and Epic Pass
  icons together. It no longer needs readable captions on bright wallpapers.
• Hidden, dimmed, incomplete or ambiguous icon layouts do not authorize entry.
  The shop icon is measured again immediately before clicking.

rc44
• Fixed STOVE startup when Windows OCR reads Secret Shop as Secret Shoo.
  Home context and the visible icon are still required before a click.
• Live hidden-home → reveal → Secret Shop entry verified without spending.

rc43
• Mouse home entry rechecks the visible controls before clicking, allowing
  animated wallpapers. Native icon matching ignores nearby bright particles.
• Secret Shop text may be joined by OCR. Mouse targets the observed icon above
  its caption, including when a saved menu reference supplies that caption.
• Failed home entry saves a private menu-only crop and recognition details.

rc42
• Mouse startup can click once to reveal idle home controls without a saved
  wallpaper. It then recognizes the Secret Shop icon and verifies shop entry.
• Visible text, blank/loading captures or a changed screen prevent the reveal
  probe. No repeated reveal clicks if the controls do not appear.

rc41
• STOVE recognizes the same saved home screen across different window shapes,
  reveals its hidden controls and enters Secret Shop automatically.
• A popup or changed page still prevents automatic home input.

Secret Shop refresh sessions through ADB or your actual mouse.
Automatic shop entry from home, Covenant Bookmark and Mystic Medal purchases,
Skystone budgets, live counters, stop keys and recent session history.

Recent improvements
• Mouse mode supports STOVE and visible emulator windows.
• Smaller Google Developer Emulator windows use the game viewport correctly.
• Smoother pointer movement and short shop drags.
• Optional tap offsets and adjustable timing variation up to ±0.10 seconds.
• Quickstart, local release notes and tested-client information in About & Credits.
• GitHub profile icon and a Buy me a coffee link on the main screen.
• More space below the estimate/calibration button and a continuous background.
• Removed Mouse preview and Friendship purchases, including in calibration.

Tested clients
Google Play Games on PC Developer Emulator and the official STOVE client of
Epic Seven. Other emulators and methods have not been tested. Use English UI.
