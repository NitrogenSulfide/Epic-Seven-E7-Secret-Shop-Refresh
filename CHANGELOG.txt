0.1.3-rc1 · Experimental session and interface cleanup

• Adds a By Blue Natto subtitle and clickable version number under Secret Shop.
• Moves the blue GitHub profile button to the header and adds a blue bug-report
  button with version/control mode prefilled. No private logs are attached.
• Enlarges the timing slider. Tap delays must be above zero and at most two
  seconds; randomized samples also respect the two-second cap.
• Records session timestamps, control mode, outcome and stop/failure reason.
  Legacy history survives migration, with the original CSV preserved as a backup.
• Exports every saved session to Excel with numeric counters and totals.
• Matching Mouse and ADB engines accept cooperative Stop, interrupt pacing
  waits and record partial sessions. Older ADB engines keep the compatibility path.
• Reduces scenery resize/theme work and skips redraws for window moves.
• Splits settings/protocol, timing, session persistence and links into modules.
• Friendship purchases and red-equipment detection are not added in this branch.

0.1.2 · Maximized STOVE Mouse fix

• Accepts STOVE's wider maximized client area instead of rejecting it as non-16:9.
• Keeps the full game view and maps Mouse targets to that same client area.
• Adds full-capture and hidden-home/purchase/repeated-refresh regressions at wide sizes.
• ADB/emulator layout requirements and Mouse focus/coverage guards are preserved.

0.1.1 · Administrator restart

• Mouse is the default for new settings; existing saved control modes are preserved.
• Mouse Start detects an elevated game and offers to restart through Windows UAC.
• Settings are saved before restarting. Select the game and press Start again;
  reopening never starts a session automatically.
• Cancelling UAC or a launch failure leaves the original app open with retry help.
• ADB and non-elevated games do not request administrator permission.

0.1.0 · First official release

• Mouse automation for official STOVE and Google Play Games Developer Emulator.
• ADB automation for the Google developer emulator.
• Home-to-shop entry, idle UI reveal, Covenant/Mystic purchases and refreshes.
• Smooth Mouse movement/dragging, bounded offsets and adjustable timing variation.
• Whole Skystone budgets, used/total counters, Stop controls and session history.
• Quickstart, release notes, day/night themes and Blue Natto credits.
• First-release testing is limited to the two clients above; other methods are untested.
• Preserves the rc51 automation code and the owner’s reported ordinary-case live passes.

Development candidate history

rc51
• Normal Mouse and ADB sessions share home entry, currency detection, scrolling
  and confirmation checks. Idle home controls can be revealed in either mode.
• Normal ADB captures support landscape 16:9 sizes from 640 × 360 and map
  observed targets back to Android coordinates. Calibration remains 1920 × 1080.
• Confirmation OCR filters dimmed inventory text and rejects conflicting items
  or prices. Captured game bounds remain fixed during a session.
• Added shared-transport regressions for hidden controls, varied sizes, both
  currencies, repeated refreshes, rejected dialogs and Stop.

rc50
• A brief visibility loss before mouse-down now discards the prepared action,
  recognizes the current home/shop/dialog again and resumes without replaying
  a stale click. Repeated failures remain bounded; covered views block input.
• Visibility changes after mouse-down remain terminal, preventing duplicate
  refreshes or purchases. Coverage diagnostics include the reported window.

rc49
• Mouse confirmations recheck the intended action, item/cost and observed
  button on a fresh capture. Background animation and tiny OCR-bound shifts
  no longer incorrectly stop an otherwise unchanged confirmation.
• Changed-confirmation diagnostics retain both dialog crops for comparison.
  Added consecutive-refresh and fresh item/cost/Stop regression checks.

rc48
• Mouse confirmation retries incomplete OCR within its existing five-second
  wait. Item, cost and fresh-dialog checks still precede the confirmation click.
• Text mismatches and changing confirmations now save private dialog crops,
  as missing buttons already did, to support diagnosis without guessing.

rc47
• Hidden-home reveal tolerates animated, dark or sparse wallpapers and
  incidental OCR lettering. When no controls are recognized, try one center
  click, wait briefly, then recognize the shop icon and verify shop entry.
• Freshly visible controls are used without an extra reveal click. Known
  dialog/loading labels and blank captures still block the reveal attempt.

rc46
• Fixed native Mouse purchases stopping at the STOVE Buy dialog: its combined
  gold-price/action button exceeded the old width limit. Purchase confirmations
  now allow that size; item, price and fresh-dialog checks still apply.

rc45
• Native Mouse home entry recognizes Sanctuary, Secret Shop and Epic Pass
  icons together. It no longer needs readable captions on bright wallpapers.
• Hidden, dimmed, incomplete or ambiguous icon layouts do not authorize entry.
  The shop icon is measured again immediately before clicking.

rc44
• Fixed STOVE startup when Windows OCR reads Secret Shop as Secret Shoo.
  Home context and the visible icon are still required before a click.
• Live hidden-home → reveal → Secret Shop entry verified without spending.

rc43
• Mouse home entry rechecks the visible controls before clicking, allowing
  animated wallpapers. Native icon matching ignores nearby bright particles.
• Secret Shop text may be joined by OCR. Mouse targets the observed icon above
  its caption, including when a saved menu reference supplies that caption.
• Failed home entry saves a private menu-only crop and recognition details.

rc42
• Mouse startup can click once to reveal idle home controls without a saved
  wallpaper. It then recognizes the Secret Shop icon and verifies shop entry.
• Visible text, blank/loading captures or a changed screen prevent the reveal
  probe. No repeated reveal clicks if the controls do not appear.

rc41
• STOVE recognizes the same saved home screen across different window shapes,
  reveals its hidden controls and enters Secret Shop automatically.
• A popup or changed page still prevents automatic home input.
